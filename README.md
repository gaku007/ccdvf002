# ログインPoC

React + Vite + TypeScriptで構成した、最小限の3画面サンプルです。

## 起動

Node.js 22.12以降（または対応する新しいLTS）を用意して、このフォルダで実行してください。

```sh
npm install
npm run dev
or
npx --yes --package=node@22 --call "npm run dev"
```

表示されたローカルURLをブラウザで開きます。

## 操作

1. ID `user`、パスワード `pass` でログインします。
2. ログイン成功画面の「マイサイトへ」を押します。
3. マイサイトで「ログアウト」を押すとログイン画面に戻ります。

誤った認証情報ではエラーを表示します。未ログインで `/#/mysite` または `/#/success` を開くとログイン画面に戻ります。同じタブでの再読み込みではログイン状態を維持します。ログアウト後はブラウザの戻る操作でも専用画面を表示しません。

## ビルド

```sh
npm run build
npm run preview
```

## 実装について

- `src/main.tsx`：3画面、認証判定、画面遷移
- `src/style.css`：スマートフォン対応のスタイル
- 画面遷移はURLのハッシュを使用するため、追加のルーターは不要です。
- 認証状態は `sessionStorage` に保存します。保存が利用できない環境ではメモリ上で動作します。
- これはフロントエンドだけで動くデモ認証です。IDとパスワードはソース内にあり、利用者が認証状態を書き換えられるため、本番のアクセス制御には使用できません。本番化にはサーバー側の認証・認可が必要です。
